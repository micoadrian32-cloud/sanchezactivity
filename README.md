
Student Record Management System is a simple web application designed to make managing student information easier. It allows users to add, view, edit, and delete student records, helping keep the data organized and updated.

The project is built using Laravel and React, with Firebase Firestore as the database. When a user saves a student record, the information is stored in Firebase and displayed in the application. Users can also update or delete records, and the changes are reflected in the database.
